# FP2級用語解説 — 計算を間違えないためのルール

相続税・贈与税・所得税など、**数値が試験の得点源になる用語**を執筆・改稿するときのチェックリストです。  
正本の執筆フローは [glossary-term-template.md](./glossary-term-template.md) を参照してください。

---

## 1. 執筆前：金額の「名前」を先に決める

同じ記事内で、次の用語を**別物**として扱います（混同禁止）。

| 用語（相続税） | 意味 |
|----------------|------|
| **課税価格** | 各取得者ごとの課税価格 |
| **課税価格の合計額** | 上記の合計 |
| **基礎控除額** | 3,000万＋600万×法定相続人の数 |
| **課税遺産総額** | 課税価格の合計額－基礎控除額（0未満は0） |
| **相続税の総額** | 法定相続分に按分→税率表適用後の税額 |
| **各人の納付税額** | 実際の取得割合で按分した最終納付額 |

記事に数値例を書く前に、**どの名前の金額を示しているか**を1行メモしてください。

## 2. 相続税の基礎控除 — 計算式と早見表

**根拠:** 相続税法第15条第1項・第2項（国税庁 [No.4152](https://www.nta.go.jp/taxes/shiraberu/taxanswer/sozoku/4152.htm)）

```
基礎控除額 ＝ 3,000万円 ＋ 600万円 × 法定相続人の数
課税遺産総額 ＝ 課税価格の合計額 － 基礎控除額（0未満は0）
```

| 法定相続人の数 | 基礎控除額 | 式の確認 |
|----------------|------------|----------|
| 1人 | **3,600万円** | 3,000＋600×1 |
| 2人 | **4,200万円** | 3,000＋600×2 |
| 3人 | **4,800万円** | 3,000＋600×3 |
| 4人 | **5,400万円** | 3,000＋600×4 |
| 5人 | **6,000万円** | 3,000＋600×5 |

**よくある算数ミス:** 3人＝3,600万円 ❌（正しくは **4,800万円**）、2人＝3,600万円 ❌（正しくは **4,200万円**）

---

## 3. 人数の数え方（基礎控除用）

人数を決めてから金額を計算します。金額から逆算しない。

| 論点 | ルール |
|------|--------|
| **受遺者** | 法定相続人でなければ人数に含めない |
| **養子** | 実子あり→1人まで／実子なし→2人まで |
| **相続放棄** | 人数計算上は**放棄がなかったものとして**数える |
| **代襲相続** | 成立時のみ孫等を法定相続人として数える |
| **被相続人** | 人数に含めない |

例：配偶者1＋実子2＋養子2 → 人数**3人**（養子1人まで）→ **4,800万円**  
（5人すべて数える誤り → 6,000万円）

## 4. 執筆後の必須チェック（公開前）

1. **式と答えを別々に検算する**  
   `600万×人数` を先に計算し、足し算 `+3,000万` を後から行う。
2. **本文・例題・FAQ・memory_tip の数字が一致する**  
   同じ家族構成なら、どの欄も同じ人数・同じ基礎控除額にする。
3. **「比較」と「差し引き」を混同しない**  
   - 基礎控除以下か → 課税価格の合計額と基礎控除額を比較  
   - 課税遺産総額 → 合計額－基礎控除額
4. **申告・納付の結論を数字と別列で書く**  
   「非課税」「申告不要」「特例のため申告必要」は同義ではない。
5. **名称が似た別制度の数字を持ち込まない**  
   贈与税基礎控除110万／所得税基礎控除48万／生命保険非課税枠500万×人数 等。
